# What Santo is
Santo turns a business's FAQs, policies and systems into an AI agent. The same agent answers customers on the business website, inside its apps through a REST API, and when other AI agents ask through MCP.

# How setup works
Step one, describe the job: who the agent works for, how it should sound, and what it hands to a person.
Step two, give it knowledge: paste or upload menus, price lists, return policies or handbooks.
Step three, connect it: add one line of code to the website, call the API, or connect over MCP.
The builder at /builder has templates for online stores, restaurants, clinics, real estate, HR and IT helpdesks, law firms, logistics and software companies.

# Coding
You do not need to know how to code. No code or coding is needed. The builder creates and publishes agents from a form. Developers can also edit YAML files.

# Examples by industry
For a restaurant, Santo answers menu, hours and allergen questions and takes table bookings.
For an online store, it answers shipping and returns questions and looks up orders.
For a clinic, it explains services and insurance and requests appointments, without giving medical advice.
For a law firm, it handles intake and books consultations, without giving legal advice.

# Actions
Agents can take actions by calling any system with a web address, like booking tools, CRMs, order databases, Zapier or n8n.

# Unknown answers and general questions
Santo answers every question. Business questions are answered only from the business's own documents, so prices and policies are never made up. General questions, facts, math and dates are answered too, using the AI model and free lookups from Wikipedia and DuckDuckGo. Businesses can switch an assistant to business-only mode.

# AI models and API keys
Santo needs no API key and has no per-message AI fees. It runs its own open-source AI model, such as Qwen or Llama, on your server. If no model server is available, a built-in engine still answers from your documents and captures leads and bookings. Paid cloud models are optional.

# Data and security
The AI runs on your own server, so conversations are not sent to an outside AI company. All data stays on your servers and conversations can be deleted any time. Admin pages and private agents need an API key.
